# Чтение документов и открытый продуктовый корпус

В **Библиотеке** выберите документ и нажмите **Открыть документ**. В отчёте откройте **Источники → Открыть документ**: читатель перейдёт на страницу цитаты. Прямая ссылка имеет вид `#/document/<id>?page=8`.

PDF открывается внутри приложения с масштабированием, миниатюрами и навигацией браузера. **Извлечённый текст** позволяет читать и искать по всем страницам; найденные страницы доступны отдельными кнопками, совпадения подсвечены. TXT отображается полностью с исходными переносами строк. HTML показывается как извлечённый текст, без исполнения исходной разметки. Скачивание оригинала остаётся отдельным действием.

Оригинал и preview проходят одинаковую проверку домена и ACL всех чанков последней версии. При закрытом чанке полное чтение запрещено (403); при отсутствии доступа к домену — 404. Ответы не кешируются. Уже загруженный в браузер документ не исчезает после отзыва прав; новый запрос снова проверяет доступ.

## Документы производителя

В `demo/documents/` сохранены ссылки и SHA-256 четырёх оригинальных PDF из [официального каталога документации ОВЕН](https://docs.owen.ru/product/pd150), полученные 2026-10-06. Это опубликованные руководства производителя, а не сгенерированные примеры; публичная доступность не означает открытую лицензию.

| Файл | Редакция | Страниц | Назначение |
|---|---|---:|---|
| `owen-pd150-short.pdf` | 1.4 | 2 | Краткое руководство ПД150 |
| `owen-pd150-r-short.pdf` | 1.5 | 2 | Краткое руководство ПД150-R с RS-485 |
| `owen-pd150i-short.pdf` | 1.1 | 2 | Краткое руководство ПД150И |
| `owen-pd150-manual.pdf` | 1.15 | 35 | Полное руководство: монтаж, питание, выходы, параметры, RS-485, обслуживание |

Точные URL, размеры и SHA-256 находятся в `demo/documents/manifest.json`. Каждая запись в библиотеке сохраняет ссылку на соответствующий PDF производителя. Редакции относятся к конкретным сохранённым файлам, не являются обещанием актуальности всех модификаций. Краткое и полное руководство одного производителя не считаются независимыми подтверждениями.

Для загрузки оригинальных PDF перед изоляцией стенда:

```bash
poetry run python -m scripts.import_product_docs --download-only
```

PDF не поставляются в Git. После загрузки их можно импортировать через UI (закрытая классификация). Для прямого административного импорта публичного корпуса запустите `poetry run python -m scripts.import_product_docs --env-file /path/to/service.env` из окружения с доступом к БД, Qdrant и моделям. Файл конфигурации должен содержать адреса, доступные именно этому процессу; Docker DNS `postgres` и `model` с хоста обычно не разрешается. Это административный offline-import, не пользовательский API. Скрипт сохраняет существующие скачанные файлы и повторно не создаёт уже ingested документ с той же контрольной суммой и URL. Сеть нужна только для отсутствующих файлов. Автоматический запуск и airgap-профиль ничего не скачивают. Прямой импорт этим скриптом по умолчанию создаёт публичные документы; домены и ограничения доступа настраиваются отдельно.

Примеры содержательных вопросов для нового исследования:

- Какие ограничения по рабочей среде и окружающей температуре установлены для ПД150? Раздели условия эксплуатации и допустимую перегрузку, укажи страницы.
- Какие настройки RS-485 и протоколы Modbus описаны в руководстве ПД150? Укажи параметры связи, ограничения кабеля и страницы источника.
- Сопоставь краткие инструкции ПД150, ПД150-R и ПД150И: питание, выходной сигнал, подключение, условия эксплуатации. Не переноси характеристики одной модификации на другую без подтверждения.
